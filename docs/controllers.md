# Controller catalog

The built-in gallery contains 39 static controller designs: 23 DualSense, nine DualShock 4, and seven Xbox. The installer, main preview, customization gallery and controller overlay all use this catalog. Buttons, sticks and triggers still show live input.

A custom skin can be installed in `skins/<name>/skin.json` next to the app. The built-in catalog is defined in `assets/controllers/catalog.json`; each entry has a PNG body, thumbnail and control atlas.
